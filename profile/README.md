# CapCognition

**CapCognition** is a framework ecosystem for **.NET** and **.NET MAUI** that makes working with camera streams and AI models simple and modular.

It provides unified APIs for accessing USB, IP, and mobile cameras, and running real-time processors such as:
- Barcode recognition (ZXing-based)
- License Plate Recognition (LPR)
- YOLO and custom ML models
